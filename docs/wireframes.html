デバイス方針

  • モバイルファースト。ワイヤーフレームは PC 幅で書いているが、実装はスマホ幅（375〜428px）を最優先で設計する
  • スマホ幅ではヘッダのタブが横スクロール、フッタは折りたたみ、カードは1列縦積みが原則
  • タッチターゲットは最小 44×44px

共通コンポーネント（デザイナーに揃えてほしいもの）

  • イベントカード: cover 画像 / タイトル / 主催者 slug / 日付 / 会場種別（対面・オンライン） / 残席バッジ
  • 主催者カード: アイコン / ユーザーネーム / あだ名 / 大学（任意） / フォロワー数 / [フォロー] ボタン
  • タグ: 大学名・カテゴリ・会場種別
  • 空状態: リストが空のとき（新歓期外・フォロー0件・お気に入り0件など）に出すプレースホルダ
  • トースト: 申込完了・キャンセル完了・エラーの一時表示

§4Event 詳細 /events/[id]

参加検討から申込ボタン押下までの意思決定を1画面で完結させる。connpass のイベント詳細ページを土台に、状態バッジ・募集期間・カレンダー同期・スマホ下部の sticky CTA・参加者/補欠者リストの並列表示を採り入れる。参加者リストの公開範囲は主催者選択・既定非公開（要件書§8）を維持し、connpass の"アイコン公開既定"はそのまま踏襲しない。

イベントの状態と CTA の変化

イベントには複数の状態があり、上部の状態バッジと申込枠の CTA が変化する。この画面のスクリーンショットを撮ったとき、どの状態にいるかが一瞥で分かることを設計の要件にする。

  • 受付前 — 状態バッジ「受付前」、CTA は「募集開始は ○/○ ○:○○」とカウント表示（クリック不可）
  • 受付中 — 通常状態、CTA は「この枠に申し込む」
  • 満員（補欠受付） — 状態バッジ「満員・補欠受付中」、CTA は「補欠登録」
  • 申込締切 — 状態バッジ「申込締切」、CTA 無効化＋理由文
  • 中止 — 上部に赤帯「このイベントは中止されました」＋主催者コメント、CTA 全消去
  • 終了 — グレー帯「イベントは終了しました」、参加枠は履歴として残す（Phase-Later で発表資料への誘導を追加）
  • ログイン中で申込済み — 上部に「あなたは○枠で申込済みです」バナー＋[マイページで詳細を見る]。既申込の枠はカード上に「申込済み」ラベル、他の枠は通常表示
  • 未ログインで申込を押した — /login?next=/events/[id]/apply?slot=... へ遷移し、ログイン後に自動で申込フローに戻る

スマホ幅での sticky CTA

スマホ幅では、上のワイヤーの [ お気に入り ] [ 主催者をフォロー ] [ シェア ] のバーは通常配置。それに加えて、画面下部に sticky で申込 CTA を常設する。スクロールで枠選択にたどり着かなくても、いつでも申込に入れるようにする。

└────────────────────────────────────────────┘

タップ → 参加枠選択（複数枠がある場合は §5 ステップ1へ、
                   単一枠なら §5 ステップ2へ直行）

▼ 満員のみのイベント: [ 補欠登録 → ]
▼ 締切/中止/終了: sticky CTA は非表示
▼ 申込済み: [ マイページで詳細を見る → ] に置き換え

  • 枠ごとの残席・価格・満員状態を確認して申し込む（または補欠登録）
  • Google カレンダーに追加 / ics ダウンロードで参加予定を自分のカレンダーに入れる
  • 対面イベントは 地図を見る ボタンから住所検索（外部マップアプリ）
  • お気に入り追加（要ログイン、未ログイン時はログイン画面へ）
  • 主催者をフォロー
  • SNS シェア（URL コピー / X / LINE）
  • 主催者ページへ遷移、同じ主催者の他イベントへの回遊
  • （公開設定時）参加者・補欠者のアイコン一覧で顔ぶれを確認、[すべて見る] で全員リスト

MVP スコープ外・将来（Phase-Later）

connpass の慣習だが、要件書 §4 スコープに入れていないもの。デザイナーには"将来入る場所"だけ意識してもらう。

  • 発表資料: URL 投稿型（PDF・スライド共有サービスへのリンク）。イベント終了後の資産化。連載やインタビューにも展開できる
  • フィード / 変更履歴: 公開・日時変更・中止のタイムライン。参加者への信頼構築
  • コメント欄: イベント詳細ページ上の質問・雑談。学生イベントでは荒れやすいので運用ルールと通報導線が先
  • 関連イベント（主催者以外）: 同じ大学・同じ日・同じカテゴリの他イベントへの横回遊

§15モーダル一覧
