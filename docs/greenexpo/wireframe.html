#項目現状の WF での扱い
1KV のキャッチコピー原稿に記載がないため、about の CONCEPT「Be Excited for GREEN」を仮置き。差し替え前提
2実行委員長・副実行委員長のプロフィール本文原稿が「〜〜〜〜〜〜」のため 要文言 のダミー行で確保（2〜3行想定）
3contact ページの文言一式リード文・問い合わせ種別・送信完了文が原稿に無い。一般的な構成で仮置き
4参加応募フォーム（原稿「（フォーム作成必要）」）自社実装か外部フォーム（Google フォーム等）かで実装量が変わる。WF では自社実装として /contact に集約。サイト内の参加ボタンはすべてこの 1 ページへ遷移し、ページ名は「お問い合わせ・参加応募フォーム」に統一（v0.2 で反映）
5参加団体一覧のカテゴリカテゴリ分類は設けず、絞り込み UI を置かない構成で確定
6ニュースのカテゴリ 4 種「すべて／お知らせ／開催前イベント／活動レポート」を CMS の分類として確定扱い
7親サイト（ヨコハマ未来創造会議）への導線v0.2 で 3 箇所に追加：①共通ヘッダー右上のテキストリンク（SP はメニュー内）②フッター「運営体制」内のボタン ③about ②「ヨコワカとは？」内のボタン。いずれも別タブで開く。遷移先 URL と、about に入れる関係性の説明文（1〜2 行）が未確定
8ロゴデータ・KV 素材の有無すべてプレースホルダ。支給時期がスケジュールに影響
93 プロジェクトの個別ページ構成図では contents 1 枚に 3 つ内包。個別ページ化するかは未確定（WF は 1 枚に内包）
10多言語対応多言語は無しとして作成
11SNS 公式アカウントの媒体WF では Instagram・X を主軸に想定し、フッター／contact に枠を 3 つ確保（3 枠目は予備）。実際に運用する媒体（Instagram／X／TikTok／YouTube／LINE 等）と各アカウント URL をご教示ください。媒体数に合わせて枠数を調整します

横浜エクスポ若者実行委員会

全国の若者と共に、横浜グリーンエクスポを盛り上げるプロジェクトです。

リボンアースプロジェクト

〜リボンで全国の想いをツナグ〜

若者一人ひとりの想いをリボンに綴り、横浜グリーンエクスポ会場内に1つのモニュメントを制作するプロジェクト。

横浜から始まったリボンアースの活動を全国へ広げ、1つのモニュメントを制作するプロジェクトです。参加者一人ひとりが「あなたの創りたい明日の風景」をテーマにリボンへ記入。全国から集まった想いを一つの作品として、横浜グリーンエクスポ会場内に展示します。
