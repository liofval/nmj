WEEKLY MEETING AGENDA

NEXT MOVE JAPAN 定例 10/8（木）

目的：HP の構成とメディアのワイヤーフレームを fix して、デザインと開発に着手できる状態にする（60分）

進行

#議題時間区分
1スケジュールの共有5分共有
2HP 構成案の確認10分決定
3メディアのワイヤーフレーム確認20分決定
4メディアの要件確定（残りの論点）10分決定
5Stripe 申請と HP 素材の依頼10分依頼
6次回までの宿題確認5分確認

議題の中身

1. スケジュールの共有5分共有

  • HP は 11/26（木）公開、メディアは Stripe の実決済込みで 1/28（木）公開
  • 確認・承認・締切はすべて木曜の定例で行う
  • 資料：https://liofval.github.io/nmj/project.html

2. HP 構成案の確認10分決定

  • 掲載項目：団体紹介・ミッション／活動実績／イベント／メンバー／お問い合わせ／SNS
  • 項目の過不足と並び順
  • お問い合わせの送信先メールアドレス

3. メディアのワイヤーフレーム確認20分決定

  • 開くページ：https://liofval.github.io/nmj/project.html#wireframe
  • 利用者の流れに沿って、実際にクリックしながら進める
    1. 参加者：ホーム → イベント一覧・検索 → イベント詳細 → 申込（入力 → 確認 → 決済 → 完了）→ マイページ
    2. 主催者：団体作成 → イベント作成 → ダッシュボード → 参加者リスト・CSV → お知らせ配信（事前メモで指摘があった画面だけ開く）
    3. うまくいかない場合：決済の失敗・期限切れ、定員オーバー、移管できない場合
  • 各画面で確かめること：足りない画面や項目はないか／文言・項目名は合っているか／操作の順番に違和感はないか
  • 最後に「この内容で fix にするか」を決める。修正が出たら、その内容と反映する期限を決める
事前のお願い（定例の前日まで）
  • 各自でワイヤーフレームを一通り触っておく
  • 気になった点は、ワイヤーフレーム右側の「メモ」欄に画面ごとに書く
  • 書き終えたら上部の「メモ入りHTMLを書き出す」で出したファイルを共有する（メモは各自のブラウザに保存されるだけなので、書き出さないと他の人には見えない）

4. メディアの要件確定（残りの論点）10分決定

  • ワイヤーで決まらなかった点
  • 団体の権限は OWNER / ADMIN の2種類でよいか
  • 有料枠のルール（支払い後の返金なし・支払期限は申込から24時間）
  • ユーザーネーム変更の制限

5. Stripe 申請と HP 素材の依頼10分依頼

  • Stripe 申請の担当者を決める（締切 10/22）。必要なもの：法人の情報、代表者の本人確認書類、入金口座
  • 学生団体の代表者が Stripe に登録できるかは制作側で調べて、10/22 までに報告する
  • HP 素材（原稿・写真・実績・メンバー紹介・SNS アカウント）の担当者を決める（締切 10/22）

6. 次回 10/15（木）までの宿題5分確認

  • 制作：デザインの方向性を2〜3案作って提示する（10/15 に1案に決める）
  • 制作：ワイヤーの修正がある場合は決めた期限までに反映する
  • 全体：HP 素材集めと Stripe 申請を始める

当日決めたいこと

  • HP の掲載項目と並び順
  • ワイヤーフレームを fix にするか（修正がある場合は内容と反映期限）
  • 有料枠のルール・権限・ユーザーネーム変更の制限
  • Stripe 申請と HP 素材の担当者
